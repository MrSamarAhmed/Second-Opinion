What this audits. Each receipt is the overlap between Qloo's descriptive metadata terms for two entities, on one of four dimensions. Thresholds are fixed and shown below; there is no composite score.
What it does not audit. Metadata overlap is not evidence of shared fans, audience size, demand, attendance, ticket sales or revenue, and it does not establish that a recommendation will succeed. The units are tags, not people.
The seed list above is a short hand-written set of artist names. Selecting one resolves that name through the Qloo API and audits the recommendations returned for it; no captured response data ships with the application.
