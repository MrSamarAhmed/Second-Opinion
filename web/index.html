Second Opinion
Qloo returns a single affinity number for every recommendation. This tool shows what, if anything, Qloo's own metadata says to back it up.
Demo hosting notice Second Opinion runs on Render's free instance. It may spin down after roughly 15 minutes without traffic, so the first visit after an idle period can take around 50 seconds while the application starts — please wait for it to load. That delay is a cold start, not an outage, and requests after it are served normally.

Agent trace
What this audits. Each receipt is the overlap between Qloo's descriptive metadata terms for two entities, on one of four dimensions. Thresholds are fixed and shown below; there is no composite score.
What it does not audit. Metadata overlap is not evidence of shared fans, audience size, demand, attendance, ticket sales or revenue, and it does not establish that a recommendation will succeed. The units are tags, not people.
How the agent works. It audits the recommendations it is handed, then looks for a verdict blocked by missing metadata on one side only. If it finds one, it may spend one follow-up lookup of that entity's own record and re-derive the verdict under the same receipt checks — never more than one per audit, and a failed lookup still costs the budget. A live audit is three Qloo requests, four when that re-read fires.
The seed list above is a short hand-written set of artist names. Selecting one resolves that name through the Qloo API and audits the recommendations returned for it; no captured response data ships with the application. The two sidebar demonstrations run the same agent over invented evidence so the follow-up behaviour can be seen without a key; the banner above their results says synthetic because they are not Qloo results.
